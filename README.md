# SIMTA
# SIMTA – Sistem Informasi Manajemen Tugas Akhir

## Deskripsi
SIMTA merupakan aplikasi berbasis web yang dikembangkan untuk membantu pengelolaan administrasi tugas akhir mahasiswa, mulai dari pengajuan judul, penetapan dosen pembimbing, pendaftaran seminar proposal, hingga administrasi sidang/komprehensif.

## Fitur Utama
- Pengajuan judul skripsi.
- Pengajuan dan penetapan dosen pembimbing.
- Pengelolaan dokumen SK pembimbing.
- Pendaftaran seminar proposal.
- Administrasi seminar proposal dan sidang/komprehensif.
- Dashboard monitoring dan rekapitulasi data tugas akhir.

## Teknologi
- Laravel
- PHP
- MySQL
- HTML, CSS, dan JavaScript
- Git dan GitHub

## Tim Pengembang
- Project Manager (PM)
- Programmer 1
- Programmer 2
- UI/UX Designer

## Kolaborasi
Pengembangan proyek menggunakan Git dan GitHub dengan ketentuan:
- `main` sebagai branch utama.
- Branch terpisah untuk pengembangan setiap fitur.
- Commit dan push untuk mengirim perubahan.
- Pull Request untuk pemeriksaan sebelum merge ke `main`.
